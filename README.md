# Netflix Data Analysis Dashboard

Netflix Analysis Project by Power BI, ITC_Team5_DEPI_R5

## Project Overview
This project analyzes Netflix content using Power BI to uncover insights about movies and TV shows available on the platform.

## Objectives
- Analyze content distribution by type (Movies vs TV Shows)
- Identify top content-producing countries
- Explore content trends over time
- Analyze ratings and genres
- Understand Netflix's content growth

## Tools Used
- Power BI
- Power Query
- DAX
- Excel/CSV Dataset

## Key Insights
- Movies represent the majority of Netflix content.
- The United States contributes the largest share of titles.
- Content production has increased significantly in recent years.
- Drama and International Movies are among the most common genres.
